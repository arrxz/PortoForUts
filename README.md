# Agna Aryaputra R. — Front End Developer Portfolio

Personal portfolio website built with HTML5, CSS3, Tailwind CSS, Bootstrap 5, GSAP, Lenis, and Barba.js.

## Tech Stack

- **Markup & Styling:** HTML5, CSS3, Tailwind CSS, Bootstrap 5
- **Animations & Transitions:** GSAP (ScrollTrigger), Barba.js (Page Transitions), Lenis (Smooth Scroll)
- **Layout:** Editorial Bento Grid

## Structure

```text
├── assets/
│   ├── css/
│   │   └── style.css

│   └── js/

├── contact.html

└── README.md
```

## Local Development

You can run this project locally with any static web server:

```bash
python -m http.server 5500
```

Open `http://localhost:5500` in your browser.
